# 📄 DocReadEx — Document Viewer & PDF Tools

**Free all-in-one Document Viewer & PDF Tools for Android**  
View any file. Create PDFs. Merge PDFs. No ads. No limits.

---

## 🚀 About

**DocReadEx** is a lightweight and powerful Android app that allows you to open, view, and manage multiple document formats in one place — along with essential PDF tools.

Most apps restrict features behind paywalls or show intrusive ads. DocReadEx is built to provide a **clean, fast, and completely free experience**.

---

## 📂 Supported File Formats

- 📄 PDF  
- 📝 Word (.docx)  
- 📊 Excel (.xlsx)  
- 📈 PowerPoint (.pptx)  
- 🖼 Images (JPG, PNG, BMP, GIF)  
- 🔧 JSON  
- ⚙️ YAML  
- 🧾 Markdown  
- 📃 Plain Text  

---

## 🛠 PDF Tools

### 🖼 Images to PDF
- Convert photos or images into PDF documents  
- Choose page size: A4, A3, Letter  
- Portrait or landscape orientation  
- Smart fit options  

### 🔗 Merge PDFs
- Combine multiple PDFs into a single file  
- Reorder files before merging  
- Save directly to device storage
